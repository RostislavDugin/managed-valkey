## MODIFIED Requirements

### Requirement: Вкладки принадлежат открытой базе

Вкладки «Управление», «Мониторинг» и «Аудит» SHALL показываться только на
странице конкретной базы. Каждая вкладка SHALL иметь собственный адрес внутри
адреса базы, сохраняться при перезагрузке и подходить для прямой ссылки.
Список баз, пустое состояние и форма создания вкладки показывать MUST NOT.

#### Scenario: Открытие раздела Valkey

- **WHEN** пользователь открывает раздел Valkey без адреса конкретной базы
- **THEN** консоль показывает список баз или пустое состояние
- **AND** вкладок на странице нет

#### Scenario: Открытие формы создания

- **WHEN** пользователь открывает форму создания базы
- **THEN** вкладок на странице нет

#### Scenario: Открытие вкладки по прямой ссылке

- **WHEN** пользователь открывает прямую ссылку на «Мониторинг» или «Аудит» базы
- **THEN** консоль открывает эту базу с указанной вкладкой
- **AND** перезагрузка не возвращает пользователя на «Управление»

#### Scenario: Заглушка мониторинга

- **WHEN** пользователь выбирает вкладку «Мониторинг» открытой базы
- **THEN** консоль показывает метрики этой базы

#### Scenario: Заглушка журнала аудита

- **WHEN** пользователь выбирает вкладку «Аудит» открытой базы
- **THEN** консоль показывает журнал действий с этой базой
