## Why

Сейчас одинаковые имена команд означают разные по стоимости проверки: корневой `just test` запускает в том числе долгую k3s-матрицу оператора и e2e, а быстрый набор оператора скрыт под именем `test-ci`. Из-за этого агенту и разработчику трудно быстро проверить только изменённый компонент и заранее понять длительность команды.

## What Changes

- **BREAKING**: `just test` в корне и приложениях становится быстрым набором без k3s и укладывается примерно в пять минут при тёплых зависимостях.
- Добавляется `just test-full` для всех реализованных тестов API, оператора и web; будущий общий integration-набор пока отображается как не реализованный.
- E2e исключается из `test` и `test-full` и запускается только отдельными командами.
- **BREAKING**: `just test-prod` переименовывается в `just test-e2e-prod`; `just test-e2e` и `just test-e2e-headed` сохраняются.
- Корневые `just format` и `just lint` обрабатывают API, оператор и web. Форматирование добавляет изменённый код выбранной области в индекс Git, линтинг не меняет файлы.
- `api`, `operator` и `web` получают одинаковые публичные команды `run`, `format`, `lint`, `test` и `test-full` в дополнение к предметным командам компонентов.
- Корневой `just run` остаётся единой командой запуска dev-инфраструктуры, оператора, API и web.
- Инструкции агентов требуют запускать локальные команды только для затронутых компонентов; общий код проверяется обоими Go-приложениями.

## Capabilities

### New Capabilities

Нет.

### Modified Capabilities

- `backend-foundation`: разделение быстрых и полных Go-тестов, единые команды форматирования и линтинга приложений.
- `backend-environments`: k3s и тестовая PostgreSQL готовятся полным набором API, а быстрый набор работает без k3s.
- `web-frontend-foundation`: публичные команды web приводятся к общему контракту приложений.
- `test-orchestration`: корневые быстрый и полный наборы разделяются, запускаются параллельно и не включают e2e.
- `ci-cd`: задания CI используют быстрые команды приложений, а ресурсоёмкие наборы остаются локальными.
- `project-skill-layout`: инструкции агентов предписывают проверки в области изменённого компонента.

## Impact

Изменение затрагивает корневой и дочерние `Justfile`, сценарии запуска тестов и проверок, GitHub Actions, `AGENTS.md` приложений, `SYSTEM.md`, `SYSTEM-DETAIL.md` и документацию e2e. Прикладные API и рабочее поведение сервисов не меняются.
