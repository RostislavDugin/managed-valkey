## ADDED Requirements

### Requirement: Агент проверяет затронутые компоненты локальными командами

Корневой `AGENTS.md` SHALL предписывать агенту запускать `format`, `lint` и быстрый `test` из `Justfile` каждого изменённого приложения. Изменение общего Go-кода SHALL требовать быстрых проверок API и оператора. Корневые команды SHALL использоваться для изменений нескольких приложений или общей обвязки. Инструкции SHALL предупреждать, что `just format` добавляет изменения своей области в индекс Git и не должен выполняться одновременно с правкой тех же файлов другим агентом.

#### Scenario: Изменён только web

- **WHEN** агент меняет только код в `web`
- **THEN** он может отформатировать, проверить линтерами и протестировать web через его `Justfile`, не запуская тесты API и оператора

#### Scenario: Изменён общий Go-код

- **WHEN** агент меняет пакет под корневым `internal`
- **THEN** он запускает быстрые проверки API и оператора, потому что общий пакет входит в оба приложения

#### Scenario: Параллельная работа агентов

- **WHEN** другой агент изменяет файлы того же компонента
- **THEN** агент не запускает добавляющий файлы в индекс `just format` до согласования владения этой областью
