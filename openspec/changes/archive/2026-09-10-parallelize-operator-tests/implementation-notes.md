## Разделение реализации

Работа начата 2026-09-10. Ориентир времени составляет около часа, но не заменяет
критерии завершения задач.

Ведущий агент владеет `scripts/test_operator.sh`, общим учётом ресурсов,
владением запусков, отменой и очисткой. Каталог передаёт запускателю имя
сценария, точное выражение `go test -run`, число нод, число реплик Envoy,
оценку памяти и длительности. Запускатель возвращает отдельный каталог результата
со статусом, журналом и длительностью. Итоговый отчёт получает только завершённые
каталоги результатов и сверяет их с исходным каталогом.

Агент A владеет поддержкой топологий в `scripts/test_environment.sh`,
`scripts/k3s_bootstrap.sh`, `scripts/check_operator_test_environment.sh`,
Compose и необходимыми изменениями интеграционных тестов. Агент B владеет
каталогом, его проверкой и `scripts/report_operator_test_matrix.sh`. Агент C
владеет режимом CI, workflow, Justfile и документацией. Общий файл меняет только
назначенный владелец; остальные передают запрос ведущему.

Начальные ограничения выбираются консервативно из фактически доступной памяти.
Подготовка артефактов и быстрые тесты ждут общего резерва 4096 MiB. Затем каждый
сценарий ждёт собственного резерва из каталога. Подготовка кластеров имеет
отдельный предел параллелизма. Целевые k3s-прогоны агенты согласуют с ведущим.
