## REMOVED Requirements

### Requirement: Будущие проверки отказов записаны рядом с кодом

**Reason**: Действующая спецификация не должна требовать конкретные TODO-файлы для уже реализованного поведения. Сценарии восстановления primary, общей интеграции и полного пользовательского пути уже находятся в operator k3s, общем интеграционном и Playwright e2e-наборах. Подтверждённо выполненные разделы `operator/TODO.md` вводят разработчика в заблуждение, но сам файл может сохраняться с отдельно подтверждёнными пробелами покрытия.

**Migration**: Удалить из `operator/TODO.md` только подтверждённо выполненные пункты. Сохранить файл, если в нём остаются несопоставленные сценарии, и удалить его только после удаления последнего пункта. Убрать из инструкций и системных документов ссылки, которые требуют TODO для уже реализованного поведения. Фактический состав обязательных проверок описывать в `test-orchestration`, локальных командах и каталогах сценариев. Архивные изменения OpenSpec не переписывать.

#### Scenario: Разработчик ищет обязательные проверки

- **WHEN** разработчик читает действующие системные документы и инструкции тестовых наборов
- **THEN** они ссылаются на реализованные unit-, operator k3s, общие интеграционные и Playwright e2e-проверки
- **AND** не требуют `operator/TODO.md` или `e2e/TODO.md` для уже реализованного поведения
- **AND** допускают `operator/TODO.md` с подтверждённо незавершёнными сценариями
