## ADDED Requirements

### Requirement: API ограничивает хранимую историю метрик

API SHALL читать `VALKEY_METRICS_RETENTION` как положительную длительность со значением по умолчанию `168h`. При запуске API SHALL удалить строки `valkey_node_metrics` с `ts` строго раньше текущего времени PostgreSQL минус срок хранения, затем SHALL повторять очистку раз в 24 часа без параллельных проходов. Ошибка очистки SHALL оставлять непросроченные строки на месте, MUST NOT делать HTTP API неготовым и SHALL допускать повтор при следующем проходе. Изменение настроенного срока SHALL применяться к последующим импортам и очисткам без изменения схемы PostgreSQL.

#### Scenario: Значение по умолчанию

- **WHEN** `VALKEY_METRICS_RETENTION` не задана
- **THEN** API использует срок хранения 168 часов

#### Scenario: Недопустимое значение

- **WHEN** `VALKEY_METRICS_RETENTION` не разбирается как длительность или не является положительной
- **THEN** API завершает запуск с ошибкой конфигурации до начала фоновых проходов

#### Scenario: Первоначальная очистка

- **WHEN** при запуске таблица содержит строку строго старше срока хранения и строку на его границе
- **THEN** первый проход удаляет старую строку и сохраняет строку на границе

#### Scenario: Ошибка ежедневной очистки

- **WHEN** PostgreSQL отклоняет очередной проход очистки, а HTTP-запросы продолжают работать
- **THEN** API сообщает ошибку в журнал и повторяет очистку в следующий запланированный проход
