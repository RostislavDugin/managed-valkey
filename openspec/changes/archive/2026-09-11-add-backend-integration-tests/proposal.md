## Why

API и оператор проверяются отдельно, поэтому обязательные тесты не подтверждают, что фоновая синхронизация проходит весь путь от HTTP-запроса до работающего Valkey и обратно в API. Нужен короткий интеграционный набор, который ловит несовместимость компонентов до сборки и развёртывания, но не повторяет сорокаминутную аварийную матрицу оператора.

## What Changes

- Добавить общий интеграционный набор с настоящими API, фоновыми обработчиками, оператором, PostgreSQL и однонодовым k3s.
- Проверить через публичный HTTP API создание `single`-инстанса, изменение его ресурсов, ротацию пароля и удаление.
- Подтверждать результат по ответам API, состоянию Kubernetes и настоящему TLS-подключению к Valkey. Тесты не создают CR напрямую и не подменяют `status`.
- Запускать четыре независимых сценария одновременно на одном стенде. Каждый сценарий получает собственные аккаунт, Valkey-инстанс и Namespace; API, фоновые обработчики, оператор, PostgreSQL, k3s и Envoy остаются общими.
- Подключить набор к корневому `just test-full` и отдельному обязательному заданию CI. Быстрый `just test` остаётся без k3s.
- Считать пять минут ориентиром длительности штатного запуска с учётом подготовки, сценариев и очистки. Превышение ориентира само по себе не делает запуск неуспешным; при функциональной ошибке сохраняется диагностика без паролей, токенов и содержимого Secret.
- Зафиксировать назначение и границы общего интеграционного набора в `AGENTS.md`.

## Capabilities

### New Capabilities

Нет.

### Modified Capabilities

- `test-orchestration`: подключить обязательный общий интеграционный набор, определить его сценарии, параллелизм, изоляцию и ориентир длительности.
- `backend-environments`: заменить неиспользуемый трёхнодовый профиль API + operator однонодовым общим стендом с одной копией каждого процесса.
- `ci-cd`: запускать короткие интеграционные тесты отдельным обязательным заданием до сборки и развёртывания.
- `project-skill-layout`: потребовать от корневого `AGENTS.md` описания назначения и правил таких тестов.

## Impact

Изменение затронет `tests/integrations`, сценарии подготовки тестового окружения и управления процессами, корневой и дочерние `Justfile`, GitHub Actions и `AGENTS.md`. Производственные HTTP-контракты, схема PostgreSQL, CRD и образы выпуска не меняются.
