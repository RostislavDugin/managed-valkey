## Why

В проекте пока нет исполняемого Playwright-набора, поэтому путь регистрации через
личный кабинет не проверяется вместе с настоящими API и PostgreSQL. Регистрация уже
работает независимо от готовности оператора и Valkey и подходит для первого
сквозного сценария и настройки общей тестовой обвязки.

## What Changes

- Добавить Playwright-набор на TypeScript, который регистрирует новый аккаунт через
  личный кабинет и проверяет открытие авторизованной страницы управления Valkey.
- В каждом запуске использовать уникальную почту и пароль `testpassword`.
- Запускать локальный сценарий на отдельной временной базе через
  `scripts/test_environment.sh exec e2e`; оператор и ресурсы Valkey в этом сценарии
  не нужны.
- Добавить headless-запуск, локальный запуск с видимым браузером и ручную проверку
  `https://app.h3llo-demo.com`.
- Подключить реализованный e2e-набор к корневому `just test` и отдельному
  обязательному заданию CI, которое выполняется параллельно с другими тестовыми
  заданиями после lint.
- Сохранить остальные сценарии из `tests/e2e/TODO.md` незавершёнными до готовности
  полного жизненного цикла Valkey.

## Capabilities

### New Capabilities

Нет.

### Modified Capabilities

- `test-orchestration`: зафиксировать первый обязательный Playwright-сценарий
  регистрации и его границы.

## Impact

Изменение затронет `tests/e2e`, сценарий запуска тестового стенда, корневые команды
`just`, общий запуск тестов и `.github/workflows/ci-cd.yml`. В e2e-наборе появятся
зависимости Playwright и Chromium. Контракты API и интерфейс личного кабинета не
меняются.
