## ADDED Requirements

### Requirement: Цепочка инструкций API

Файл `api/CLAUDE.md` SHALL быть относительной символической ссылкой на `api/AGENTS.md`. Локальные инструкции API SHALL сначала подключать корневой `AGENTS.md`, затем применимые разделы `SYSTEM.md`, правила Go, HTTP, PostgreSQL и миграций.

#### Scenario: Работа агента в API

- **WHEN** Codex или Claude начинает задачу в каталоге `api`
- **THEN** по локальной цепочке ему доступны общие правила проекта и инструкции по ответственности API, времени, логам, миграциям и современному Go

### Requirement: Цепочка инструкций оператора

Файл `operator/CLAUDE.md` SHALL быть относительной символической ссылкой на `operator/AGENTS.md`. Локальные инструкции оператора SHALL сначала подключать корневой `AGENTS.md`, затем применимые разделы `SYSTEM.md` и правила Go, Kubernetes, времени и логирования. Они SHALL запрещать доступ оператора к PostgreSQL и HTTP API сервиса.

#### Scenario: Работа агента в операторе

- **WHEN** Codex или Claude начинает задачу в каталоге `operator`
- **THEN** по локальной цепочке ему доступны общие правила проекта, границы ответственности оператора и правила работы с `controller-runtime`

### Requirement: Адаптированные правила Go

Локальные инструкции API и оператора SHALL содержать правила пустых строк между логическими блоками, редких комментариев о причине решения, времени в UTC, структурированного `slog`, идиом поддерживаемой версии Go и запуска локального `just lint`. Они MUST NOT переносить соглашения другого проекта, для которых нет соответствующего компонента или решения в Managed Valkey.

#### Scenario: Проверка заимствованных правил

- **WHEN** разработчик сравнивает локальные инструкции с указанным исходным Go-гайдом
- **THEN** в них нет чужих имён, обязательного Swagger, чужой схемы DI или структуры CRUD, а применимые правила сформулированы для API и оператора Managed Valkey

### Requirement: Корневые инструкции описывают pre-commit

Корневой `AGENTS.md` SHALL описывать проверки frontend и Go в `.githooks/pre-commit`, включая автоматическое добавление исправленного форматтером staged-кода и отмену коммита при ошибке линтера или сборки.

#### Scenario: Разработчик готовит коммит с Go-кодом

- **WHEN** разработчик читает раздел о pre-commit в корневом `AGENTS.md`
- **THEN** он видит, какие команды выполняются для API и оператора и какие изменения hook добавляет в индекс автоматически
