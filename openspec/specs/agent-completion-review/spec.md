# agent-completion-review

## Purpose

Определяет автоматическую проверку планов и результатов Codex и Claude Code перед завершением работы агента.

## Requirements

### Requirement: Проверка завершённого планирования

Codex и Claude Code SHALL перед завершением планирования запускать отдельную модель, которая проверяет план и ответ агента по правилам `humanizer`, применимым `AGENTS.md`, `CLAUDE.md`, запросу пользователя и связанным артефактам OpenSpec.

#### Scenario: План соответствует требованиям

- **WHEN** агент завершил планирование и план не содержит существенных нарушений
- **THEN** проверяющая модель разрешает завершить ответ

#### Scenario: План требует исправления

- **WHEN** проверяющая модель находит конкретное нарушение
- **THEN** основной агент получает замечание, исправляет план и повторно проходит проверку

### Requirement: Проверка результата выполнения

После изменения рабочего дерева или `HEAD` Codex и Claude Code SHALL перед завершением проверять полный `git diff`, итоговый ответ и связанные спецификации. Проверка SHALL учитывать изменения в индексе, вне индекса и неотслеживаемые файлы, но SHALL игнорировать неизменившийся `git diff`, существовавший до текущего запроса.

#### Scenario: Реализация соответствует плану и спецификации

- **WHEN** `git diff` технически обоснован, ограничен задачей и соответствует принятым требованиям
- **THEN** проверяющая модель разрешает завершить ответ

#### Scenario: Реализация требует исправления

- **WHEN** `git diff` или итоговый ответ нарушает инструкции, принятый план либо спецификацию
- **THEN** основной агент получает конкретное замечание, исправляет результат и повторно проходит проверку

### Requirement: Автоматическая синхронизация спецификации

Если последняя явная воля пользователя и согласованный результат однозначно показывают, что OpenSpec устарел, основной агент SHALL исправить связанные спецификации и артефакты изменения без дополнительного подтверждения пользователя. При отсутствии таких доказательств результат SHALL соответствовать действующей спецификации.

#### Scenario: OpenSpec не отражает согласованное поведение

- **WHEN** проверяющая модель обнаруживает однозначно устаревшее требование OpenSpec
- **THEN** она отклоняет результат с указанием нужных правок, а основной агент обновляет OpenSpec и снова проверяет согласованность

### Requirement: Модели проверки

Codex SHALL выполнять проверку моделью `gpt-5.6-sol` с уровнем рассуждения `low`. Claude Code SHALL выполнять проверку моделью `opus` с уровнем рассуждения `low`. Проверяющий процесс MUST иметь доступ к проекту только для чтения.

#### Scenario: Запуск проверки в Codex

- **WHEN** срабатывает хук завершения Codex
- **THEN** отдельный процесс проверки использует `gpt-5.6-sol` и `model_reasoning_effort=low`

#### Scenario: Запуск проверки в Claude Code

- **WHEN** срабатывает хук завершения Claude Code
- **THEN** отдельный процесс проверки использует `opus` и `--effort low`
