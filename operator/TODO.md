# Следующие этапы оператора

## Сквозная проверка с API

Добавить отдельный интеграционный набор, который пройдёт путь от HTTP-запроса и
PostgreSQL через `ValkeyInstance` и оператор обратно до сохранённого состояния.
Сейчас API проверяет синхронизацию с Kubernetes без оператора, а оператор
проверяется напрямую через CR и Secret на отдельном k3s.

## Изменение whitelist

Добавить изменение whitelist работающего инстанса как сохраняемую операцию.
Первоначальный whitelist уже применяется при создании, но его изменение в новом
поколении пока возвращает `UnsupportedChange`.

## Наблюдаемость

Добавить производителя снимков `status.metrics`: собирать показатели Valkey из
`INFO`, получать CPU текущего контейнера через `metrics.k8s.io` и сохранять не
больше одного снимка на ordinal. CRD, проверяемый импорт в API, срок хранения и
экран мониторинга уже готовы. Отдельно добавить экспорт метрик жизненного цикла
оператора. Эта работа не входит в текущий этап HA и изменений инстанса.

## Проверка в h3llo

Проверить на облачном стенде порядок уничтожения VM и удаления Node, внешний
балансировщик, исходный адрес клиента и требования `ContainerRestartRules`.
Локальный k3s подтверждает поведение оператора, но не действия облачной панели.
