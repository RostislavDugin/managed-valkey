# Движение

## Что уже есть в продукте

| Что | Длительность | Кривая |
|---|---|---|
| Открытие и закрытие боковых панелей оболочки | 200ms | `ease` |
| Появление и скрытие вложенного меню навигации | 200ms | `opacity` переход |
| Наведение на кнопку, поле, пункт навигации | быстрый переход цвета | `ease` |
| Переход между страницами лендинга | View Transitions API | браузерная |
| Бегущая строка в блоке про защиту | ~30s на цикл | `linear`, бесконечно |

Лендинг использует нативные переходы между страницами: элементы помечены атрибутами
`vt-update`, `vt-name`, `vt-share`, `vt-enter`, `vt-exit`, и браузер сам анимирует
общие элементы между документами. Консоль этим не пользуется, там движение сводится
к раскрытию панелей и состояниям наведения.

## Правила

**Длительность 150–300ms.** Всё, что короче, читается как мгновенная подмена, всё,
что длиннее, начинает тормозить работу. 200ms из оболочки — хороший ориентир по
умолчанию.

**Уход быстрее прихода.** Закрытие панели или модального окна делаем примерно на
треть быстрее открытия: пользователь уже принял решение уйти, и ждать нечего.

**Движение объясняет, откуда взялся элемент.** Выдвижная панель приезжает с той
стороны, где живёт её кнопка. Выпадающий список раскрывается от поля, а не появляется
по центру экрана. Если анимация не отвечает на вопрос «откуда это взялось», она
декоративная, и её лучше убрать.

**Анимируем `transform` и `opacity`.** Анимация `width`, `height`, `top` и `left`
вызывает пересчёт раскладки на каждом кадре. Для раскрытия блока по высоте
используем `grid-template-rows` или анимацию `opacity` с заранее зарезервированным
местом.

**Мгновенная обратная связь на действие.** Нажатие кнопки должно отзываться сразу
(в Mantine за это отвечает класс `mantine-active`), а результат может приходить
позже с индикатором загрузки. Ноль анимации на нажатие ощущается как неработающая
кнопка.

**Уважаем `prefers-reduced-motion`.** Пользователю с этой настройкой оставляем
изменение состояния без перемещения:

```css
@media (prefers-reduced-motion: reduce) {
  *,
  *::before,
  *::after {
    animation-duration: 0.01ms !important;
    animation-iteration-count: 1 !important;
    transition-duration: 0.01ms !important;
    scroll-behavior: auto !important;
  }
}
```

Бегущая строка на лендинге при этой настройке должна останавливаться: непрерывное
движение в поле зрения — частая причина, по которой её включают.

**Скелетоны вместо спиннеров там, где известна форма контента.** Страница консоли на
загрузке показывает скелетон заголовка и центрированный лоадер под ним. Если раскладка
будущего содержимого известна заранее, лучше показать её каркас: это убирает скачок
раскладки в момент прихода данных.
