# Отступы, радиусы, высота

## Отступы

| Токен | Значение | Где применяется |
|---|---|---|
| `h3_xs` | 8px | зазор между иконкой и подписью, между кнопками в группе |
| `h3_sm` | 12px | внутренний отступ строки списка, горизонтальный отступ панели |
| `h3_md` | 16px | внутренний отступ карточки, зазор между полями формы |
| `h3_lg` | 24px | отступ между группами полей |
| `h3_xl` | 32px | отступ между разделами страницы |

Шкала не степенная: шаги 8, 12, 16, 24, 32 растут мягче, чем удвоение. Это заметно
на плотных экранах консоли, где между 8 и 16 нужен промежуточный шаг.

Значения вне шкалы в продукте встречаются, и это осознанные исключения композиции:
заголовок страницы отбит сверху на 64px и снизу на 48px, низ страницы имеет запас
120px, строка формы держит минимальную высоту 60px. Такие числа появляются в макете
страницы, но не внутри компонентов.

## Радиусы

| Токен | Значение | Где применяется |
|---|---|---|
| `h3_none` | 0 | плашка цены на лендинге, элементы pixel-grid |
| `h3_xs` | 4px | мелкие плашки, индикатор сегментированного контрола |
| `h3_sm` | 6px | радиус по умолчанию: кнопки, поля, панели |
| `h3_md` | 8px | слайдер, карточка выбора |
| `h3_lg` | 12px | крупная карточка |
| `h3_xl` | 16px | модальное окно |
| `h3_full` | 9999px | аватар, круглая иконка, точка радио |

Радиус по умолчанию 6px. Заметное исключение — плашка цены на лендинге: она
намеренно прямоугольная (`rounded-none`), потому что читается как выделение маркером,
а не как элемент управления.

## Тени

Теней ровно две, и обе используются редко.

```css
--h3-shadow-default: 0px 1px 3px 0px rgb(from #1B1B1B r g b / 50%);
--h3-shadow-primary:
  0 2px 4px 0 rgba(0, 0, 0, 0.10),
  0 0 8px 0 rgba(134, 252, 188, 0.5);
```

`h3_default` поднимает всплывающий слой над страницей: выпадающий список, поповер,
меню. `h3_primary` добавляет мятное свечение и предназначена для элемента, который
надо выделить как активный или рекомендованный.

Иерархия в интерфейсе строится не тенями, а поверхностями: `h3_bg` → `h3_bg_1` →
`h3_bg_2` → `h3_bg_3`. Тень означает «этот слой оторвался от страницы», и если слой
не всплывающий, тень не нужна.

## Границы

Толщина границы везде 1px. Даже там, где границы нет, компонент объявляет
`1px solid transparent`: так кнопка с рамкой и кнопка без неё имеют одинаковый размер,
и при наведении ничего не дёргается.

Цвет по умолчанию `h3_border`. Про то, что `#E9E9E9` не проходит порог 3:1 для контура
интерактивного контрола, написано в [../quality/contrast-audit.md](../quality/contrast-audit.md).

## Плотность

Консоль плотная: строка навигации, строка калькулятора и поле формы занимают минимум
вертикали. Лендинг разреженный: секции занимают экран целиком, между заголовком и
текстом лежит 20–40px.

Это две разные плотности одной системы, и смешивать их не надо. Страница консоли,
свёрстанная с ритмом лендинга, теряет обзорность, а секция лендинга с плотностью
консоли выглядит как административная панель.
