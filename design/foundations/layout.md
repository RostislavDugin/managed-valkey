# Каркас и сетка

## Брейкпоинты

| Токен | Значение | Что происходит |
|---|---|---|
| `xs` | 576px | стандартный Mantine, в продукте почти не используется |
| `sm` / `mobile` | 768px | граница мобильной вёрстки |
| `md` | 992px | стандартный Mantine |
| `tablet` | 1024px | появляются боковые панели, исчезает нижний футер |
| `1280` | 1280px | правая панель перестаёт быть выдвижной |
| `lg` | 1200px | стандартный Mantine |
| `xl` / `wide` | 1408px | боковые панели расширяются с 256px до 280px |

Продуктовые псевдонимы (`mobile`, `tablet`, `wide`, `1280`) заведены поверх
стандартной сетки Mantine специально, чтобы в коде читалось намерение, а не число.
В новых компонентах опирайся на них.

## Оболочка консоли

```
┌──────────────────────────────────────────────────────────────┐
│ header 52px: хлебные крошки слева, управление справа         │
├────────────┬────────────────────────────────┬────────────────┤
│ navbar     │ main                           │ aside          │
│ 256px      │ container h3_page 784px        │ 256px          │
│ (280px     │ по центру                      │ (280px         │
│  от 1408)  │                                │  от 1408)      │
│            │                                │                │
│ логотип    │                                │ калькулятор    │
│ проекты    │                                │ стоимости      │
│ разделы    │                                │                │
│ ─────────  │                                │                │
│ баланс     │                                │                │
│ профиль    │                                │                │
│ иконки     │                                │                │
└────────────┴────────────────────────────────┴────────────────┘
```

| Параметр | Значение |
|---|---|
| Высота шапки | 52px |
| Ширина навигации | 256px от 1024px, 280px от 1440px |
| Ширина правой панели | та же, что у навигации |
| Нижний футер | 52px, только уже 1024px |
| Внутренний отступ оболочки | 0 |
| Контейнер контента | 784px (`h3_page`), центрируется |

Шапка, навигация, правая панель и футер имеют границу со стороны контента
(`data-with-border`). Отступ у оболочки нулевой: поля создаёт сам контейнер контента,
а не каркас, поэтому панели прижаты к краям окна.

Ниже 1024px навигация и правая панель превращаются в выдвижные, а внизу появляется
футер с логотипом и бургером. Правая панель на мобильном закрыта по умолчанию.

## Вертикальный ритм страницы

| Элемент | Отступ |
|---|---|
| Заголовок `h1` | 64px сверху, 48px снизу |
| Низ страницы | 120px |
| Строка формы | минимальная высота 60px |

Запас 120px внизу оставлен не для красоты: без него последнее поле формы упирается
в край окна, и выпадающему списку некуда раскрыться вниз.

## Сетка формы

Форма в консоли двухколоночная: подпись слева, контрол справа.

```
┌─────────────────────────┬──────────────────────────────────┐
│ Имя виртуальной машины ⓘ│ [ virtual-machine-1474    ] [⟳] │
└─────────────────────────┴──────────────────────────────────┘
   левая колонка               правая колонка, 100% ширины
   подпись h3_md 17px          контрол размера md
   + иконка подсказки 16px
```

Правила:

- подпись всегда видима, плейсхолдер её не заменяет;
- рядом с подписью стоит иконка `info` цвета `h3_text_1` с подсказкой при наведении;
- контрол растягивается на всю ширину правой колонки;
- вспомогательное действие (сгенерировать имя, добавить ключ) стоит справа от поля
  отдельной иконочной кнопкой варианта `h3_stroke` и размера `input-md` или `input-sm`,
  чтобы её высота совпала с высотой поля;
- поле, которому нужна вся ширина строки (группа выбора ОС), выносится в
  полноширинный слот и подпись встаёт над ним.

## Сетка карточек выбора

Группа радио-карточек (выбор операционной системы) раскладывается адаптивно:

| Ширина окна | Колонок |
|---|---|
| < 768px | 1 |
| 768–991px | 2 |
| ≥ 992px | 3 |

Зазор 10px по обеим осям.

## Правая панель как живой расчёт

Правая панель в форме создания ресурса — это калькулятор стоимости, который
пересчитывается на каждое изменение формы. Он состоит из переключателя периода
(месяц, день, час) и списка строк «параметр — цена», а внизу итог более крупным
кеглем и иконка с пояснением, что входит в сумму.

Панель не прокручивается вместе с формой и остаётся на экране: пользователь меняет
конфигурацию и сразу видит цену. Это ключевой приём консоли, и в новых формах
создания ресурсов его стоит повторять.

## Прокрутка

Длинные списки в навигации завёрнуты в `ScrollArea` с тонкой полосой (4px) и
градиентными тенями у краёв. Тени показывают, что содержимое продолжается за границей
области, и включаются по атрибутам `data-at-top` / `data-at-bottom`.
