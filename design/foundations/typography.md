# Типографика

## Семейства

| Роль | Семейство | Запасные |
|---|---|---|
| Текст и заголовки | `manrope` | `-apple-system`, `BlinkMacSystemFont`, `Segoe UI`, `Roboto`, `Helvetica`, `Arial`, `sans-serif` |
| Моноширинный | `robotoMono` | `ui-monospace`, `SFMono-Regular`, `Menlo`, `Monaco`, `Consolas`, `Liberation Mono`, `Courier New`, `monospace` |

Заголовки не имеют отдельного семейства: `fontFamilyHeadings` ссылается на основное.
Шрифты в продукте самохостятся (`/_next/static/media/*.woff2`) и подключаются с
`rel="preload"`, поэтому имена в CSS указаны строчными и без веб-безопасных синонимов.

Моноширинный шрифт в консоли отвечает за технические значения: идентификаторы,
адреса, версии, всё, что пользователь может скопировать. На лендинге он взял на себя
больше — там моноширинными набраны подзаголовки, кнопки и футер, и это осознанная
часть интонации бренда.

## Начертания

| Токен | Значение | Где |
|---|---|---|
| regular | 450 | основной текст |
| medium | 600 | подписи полей, названия в карточках |
| bold | 700 | заголовки всех уровней |

450 вместо привычных 400 — не опечатка. Manrope переменный, и на светлом фоне
чуть более плотное начертание читается ровнее.

## Интерфейсная шкала

Пять ступеней. Интерлиньяж задан в пикселях, а не множителем: это делает высоту строки
предсказуемой в плотных таблицах и панелях.

| Токен | Размер | Интерлиньяж | Где применяется |
|---|---|---|---|
| `h3_xs` | 13px | 15px | подписи разделов навигации, служебные кнопки |
| `h3_sm` | 15px | 19px | хлебные крошки, строки калькулятора, вторичный текст |
| `h3_md` | 17px | 23px | подпись поля формы, основной текст |
| `h3_lg` | 19px | 25px | подзаголовок блока |
| `h3_xl` | 21px | 29px | заголовок третьего уровня |

## Заголовочная шкала

Пять ступеней с относительным интерлиньяжем, близким к единице: заголовки набираются
плотно, строки почти касаются друг друга.

| Токен | Размер | Интерлиньяж |
|---|---|---|
| `headline_xs` | 25px | 1.2 |
| `headline_sm` | 30px | 1.067 |
| `headline_md` | 35px | 1.029 |
| `headline_lg` | 40px | 1.0 |
| `headline_xl` | 50px | 1.042 |

## Карта заголовков

| Тег | Токен | Размер / интерлиньяж |
|---|---|---|
| `h1` | `headline_sm` | 30px / 1.067 |
| `h2` | `headline_xs` | 25px / 1.2 |
| `h3` | `h3_xl` | 21px / 29px |
| `h4` | `h3_lg` | 19px / 25px |
| `h5` | `h3_md` | 17px / 23px |
| `h6` | `h3_sm` | 15px / 19px |

Начиная с `h3` заголовки берутся из интерфейсной шкалы. Смысл в том, что внутри
страницы консоли заголовок третьего уровня — это подпись группы, а не самостоятельный
титул, и он должен быть соразмерен окружающему тексту.

Все заголовки переносятся с `text-wrap: balance`. Строки в многострочном заголовке
выравниваются по длине, и «висячего» одинокого слова не остаётся.

## Слой лендинга

Лендинг живёт на Tailwind и своей шкале классов. Соответствие приблизительное:
это разные кодовые базы, и точные размеры классов лежат во внешнем CSS сайта.

| Класс лендинга | Роль | Ближайший токен консоли |
|---|---|---|
| `headline-2xl-text` | заголовок героя | крупнее `headline_xl` |
| `headline-xl-text` | заголовок секции с иллюстрацией | `headline_xl` |
| `headline-lg-text` | заголовок обычной секции | `headline_lg` |
| `headline-sm-text` | заголовок карточки тарифа | `headline_sm` |
| `headline-xs-text` | слоган в футере | `headline_xs` |
| `body-mono-xl` | подзаголовок секции | `h3_xl`, моноширинный |
| `body-mono-lg` | текст карточки, ссылки футера | `h3_lg`, моноширинный |
| `body-mono-md` | подпись в шапке | `h3_md`, моноширинный |
| `body-mono-sm` | копирайт | `h3_sm`, моноширинный |
| `body-xl` / `body-lg` / `body-md` | текст карточек и колонок футера | `h3_xl` / `h3_lg` / `h3_md` |

Точные значения размеров классов лендинга в предоставленном HTML не видны, они
приходят из внешнего файла стилей. Прежде чем опираться на эту таблицу в вёрстке,
проверь фактические значения в прод-CSS.

## Правила набора

Размер основного текста не опускаем ниже 13px (`h3_xs`), и эта ступень только для
служебных подписей, а не для содержательного текста.

Числа в интерфейсе набираются с неразрывными пробелами в разрядах и перед единицей:
`1 926,00 ₽`, `2 ГБ`, `15 ГБ`. Формат цен и единиц описан в
[../content/voice-and-tone.md](../content/voice-and-tone.md).

Длинный текст в узких контейнерах обрезаем многоточием через `data-truncate="end"`,
а не переносом: хлебные крошки и названия проектов ограничены 200px каждое, и
многоточие в конце сохраняет начало имени, по которому пользователь и опознаёт объект.
