# Кнопки

В консоли четыре варианта кнопок и один принцип: вариант выбирается по весу действия
на экране, а не по тому, как хочется покрасить.

| Вариант | Вес действия | Пример |
|---|---|---|
| `h3_accent` | главное действие страницы, одно на экран | «Собрать и запустить» |
| `h3_secondary` | частое второстепенное действие | плюс и минус у поля размера диска |
| `h3_stroke` | действие рядом с полем, которому нужна видимая граница | «Сгенерировать имя», «Добавить ключ» |
| `h3_ghost` | действие без веса | иконки в нижней панели, «Создать проект» |

## Спецификации

### `h3_accent`

| Свойство | Светлая | Тёмная |
|---|---|---|
| Заливка | `var(--mantine-color-variant-h3_accent)` → `#1B1B1B` | → `#86FCBC` |
| Наведение | `var(--mantine-color-variant-h3_accent-hover)` → `#5A5A5A` | → `#B6FDD7` |
| Текст | `h3_text_inverse` `#FFFFFF` | `h3_text_inverse` `#1B1B1B` |
| Граница | `1px solid transparent` | то же |

Заливка не задаётся вручную: обе схемы разведены внутри переменной. Подробнее про
эту асимметрию — в [../foundations/color.md](../foundations/color.md).

В форме создания ресурса кнопка растянута на ширину правой колонки (`data-block`)
и отбита сверху на 16px.

### `h3_secondary`

| Свойство | Значение |
|---|---|
| Заливка | `h3_bg_2` |
| Наведение | `h3_bg_3` |
| Текст | `h3_text` |
| Граница | `1px solid transparent` |

### `h3_stroke`

| Свойство | Значение |
|---|---|
| Заливка | `transparent` |
| Наведение | `h3_bg_2` |
| Текст | `h3_text` |
| Граница | `1px solid h3_border` |

### `h3_ghost`

| Свойство | Значение |
|---|---|
| Заливка | `transparent` |
| Наведение | `h3_bg_2` |
| Текст | `h3_text` |
| Граница | `1px solid transparent` |

Прозрачная граница у вариантов без рамки нужна, чтобы кнопки всех вариантов имели
одинаковый габарит и не смещали соседей при смене состояния.

## Размеры

Кнопки используют размерную шкалу Mantine. В консоли встречаются:

| Размер | Высота | Где |
|---|---|---|
| `h3_xs` | `var(--button-height-xs)`, отступ по горизонтали 10px, кегль 13px | «Создать проект» в шапке списка проектов |
| по умолчанию (`md`) | 42px | главная кнопка формы |

Иконочные кнопки (`ActionIcon`):

| Размер | Где |
|---|---|
| `md` | панель иконок внизу навигации, шаг числового поля |
| `input-md` | кнопка справа от поля размера `md` |
| `input-sm` | кнопка справа от поля размера `sm` |
| 36px явно | шеврон раскрытия в пункте навигации, там же нулевой радиус |

Размеры `input-*` существуют ровно для того, чтобы иконочная кнопка совпала по высоте
с соседним полем. Если ставишь кнопку рядом с полем, бери их, а не `md`.

## Иконки

Иконки — Lucide, штрих 1.5, размер 16px, `currentColor`. Эмодзи вместо иконок не
используем.

У кнопки может быть секция слева или справа от подписи (`data-with-right-section`).
Зазор между иконкой и текстом 8px.

## Состояния

| Состояние | Что меняется |
|---|---|
| Наведение | заливка на `hover`-токен варианта |
| Нажатие | класс `mantine-active`, лёгкое сжатие |
| Фокус с клавиатуры | видимое кольцо фокуса, снимать нельзя |
| Загрузка | индикатор внутри кнопки, кнопка заблокирована |
| Заблокировано | `h3_disabled` фон, `h3_disabled_color` текст, курсор `not-allowed` |

Кольцо фокуса в Mantine появляется только при навигации с клавиатуры
(`mantine-focus-auto`). Заменять его на `outline: none` нельзя ни при каких условиях:
без него клавиатурный пользователь теряет позицию на странице.

## Обязательные требования

Иконочная кнопка без подписи обязана иметь `aria-label`. В консоли это соблюдается:
«Свернуть Сеть», «Сгенерировать случайное имя», «Toggle color scheme». Кнопка с одной
иконкой и без имени для скринридера — просто «кнопка».

После нажатия на кнопку, запускающую операцию, показываем состояние: индикатор в
кнопке, потом уведомление об успехе или ошибке. Нажатие без видимого отклика
пользователь трактует как поломку и жмёт ещё раз.

Минимальная область нажатия 44×44px на сенсорных экранах. Иконочные кнопки размера
`md` (36px) этого не дают, поэтому на мобильном им нужен либо больший размер, либо
расширенная область нажатия через псевдоэлемент.
