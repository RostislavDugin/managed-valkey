# Поля и элементы управления

Все поля используют вариант `h3_default` и размер `md` в основной форме,
`sm` для второстепенных полей (например выбора SSH-ключа).

## Текстовое поле

| Свойство | Значение |
|---|---|
| Высота | `var(--input-height-md)` |
| Кегль | `var(--mantine-font-size-md)` |
| Граница | `1px solid h3_border` |
| Радиус | `h3_sm` 6px |
| Плейсхолдер | `h3_text_1` |

Плейсхолдер показывает пример значения (`my-vm`), а не название поля. Название всегда
стоит отдельной видимой подписью слева.

Поле может иметь секцию слева или справа: иконку, кнопку, единицу измерения. Ширина
секции задаётся через `--input-right-section-width`, а если секция некликабельна,
её события отключаются (`--input-right-section-pointer-events: none`), чтобы клик
по ней попадал в поле.

## Числовое поле

Числовое поле показывает значение вместе с единицей прямо в тексте: `15 ГБ`.
Справа стоят две кнопки `h3_secondary` размера `md` с иконками минуса и плюса,
подписанные `aria-label` «Уменьшить» и «Увеличить». Ширина правой секции 76px.

Ввод с клавиатуры остаётся доступным: `inputmode="decimal"`.

## Выпадающий список

| Свойство | Значение |
|---|---|
| Правая секция | шеврон, размер по размеру поля |
| Поведение | `readonly`, курсор `pointer` |
| Роль | `combobox` с `aria-haspopup="listbox"` |
| Список | `role="listbox"`, элементы `role="option"` |
| Выбранный элемент | галочка слева и `aria-selected="true"` |
| Максимальная высота списка | 220px, дальше прокрутка |

Отключённый список получает `data-disabled` и не принимает фокус. В карточках выбора
операционной системы список версий заблокирован до тех пор, пока не выбрана сама
система: пока радио не активно, версию менять нечего.

## Радиогруппа карточками

Ключевой элемент формы создания ресурса. Каждая карточка содержит радио с названием
и выпадающий список с версией.

| Свойство | Значение |
|---|---|
| Цвет выбранного | `h3_bg_accent` `#86FCBC` |
| Цвет точки внутри | `h3_mint-8` `#025829` |
| Граница выбранной карточки | `h3_border_accent` |
| Внутренний отступ | 10px |
| Раскладка | 1 колонка до 768px, 2 до 992px, 3 дальше |

Контраст точки на мятной заливке 6.86:1, читается уверенно. Состояние передаётся
и цветом, и формой (точка внутри круга), поэтому не теряется при дальтонизме и
в чёрно-белой печати.

## Слайдер

| Свойство | Значение |
|---|---|
| Вариант | `h3_slider_default` |
| Размер | `xl` |
| Цвет заполненной части | `h3_border_accent` `#6CDB9F` |
| Радиус | 8px |
| Ползунок | квадратный со скруглением, `h3_bg_accent` |

Слайдер используется для дискретных ступеней с подписями: vCPU (1, 2, 4, 8, 16, 32, 64)
и RAM (2, 4, 8, 16 ГБ). Подписи ступеней всегда видимы под дорожкой. У ползунка есть
`role="slider"` с `aria-valuemin`, `aria-valuemax`, `aria-valuenow`, и он управляется
стрелками с клавиатуры.

Слайдер с подписями работает, пока ступеней немного и они помещаются в строку. Если
значений больше десятка или шаг непредсказуемый, лучше числовое поле.

Ползунок мятного цвета на белом фоне даёт контраст 1.71:1. Форму он не теряет
(это заметный квадрат), но полагаться на его цвет как на единственный признак
положения нельзя. Подписи ступеней тут обязательны.

## Переключатель

| Свойство | Значение |
|---|---|
| Вариант | `h3_default` |
| Положение подписи | справа |
| Подпись | «Вкл» / «Выкл», текстом, а не только цветом |

Подпись рядом с переключателем важна: положение и цвет вдвоём читаются плохо, если
пользователь не различает мятный и серый.

## Общие правила

**У каждого поля есть видимая подпись.** Плейсхолдер подписью не считается: он
исчезает при вводе, и пользователь остаётся с заполненным полем без названия.

**Ошибка стоит у поля.** Не сводкой сверху формы, а под тем полем, где она возникла,
и вместе со значком, а не одним красным цветом.

**Проверяем на потере фокуса, а не только на отправке.** Пользователь узнаёт о
проблеме сразу, а не после того, как заполнил всю форму.

**Подсказка под вопросом.** Иконка `info` рядом с подписью объясняет, что это за
параметр и на что он влияет. Она нужна там, где название параметра не самоочевидно
(«Публичный IPv4», «Капсулы»), и не нужна там, где очевидно («Имя»).

**Значение по умолчанию заполнено.** Форма создания ВМ открывается с готовой рабочей
конфигурацией: ОС выбрана, имя сгенерировано, сеть подставлена. Пользователь может
нажать кнопку сразу, и это правильное поведение для формы создания ресурса.
