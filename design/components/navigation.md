# Навигация

## Пункт навигации (`NavLink`)

| Свойство | Значение |
|---|---|
| Вариант / размер | `h3_default` |
| Заливка | `transparent` |
| Текст | `h3_text` |
| Наведение | `h3_bg_3` |
| Иконка слева | Lucide, 16px, штрих 1.5 |
| Иконка справа | шеврон у раскрывающихся пунктов |

Вложенность передаётся отступом слева: верхний уровень 0, второй 20px, третий 40px.
Элемент третьего уровня получает иконку-точку (`circle-small`) вместо смысловой:
на этой глубине иконка уже не помогает опознать раздел, а служит маркером списка.

Раскрывающийся пункт разделён на две зоны: ссылка ведёт в раздел, отдельная иконочная
кнопка справа сворачивает поддерево. У кнопки нулевой радиус и `aria-expanded`,
подпись вида «Свернуть Сеть». Так клик по названию не превращается в случайное
сворачивание.

Порядок разделов проекта в консоли: Инстансы, Капсулы, Диски, Базы данных, Сеть
(с вложенными подсетями), Балансировщики, S3 хранилище, Kubernetes, Бэкапы и снимки.

## Нижний блок навигации

Прижат к низу (`margin-top: auto`) и содержит то, что нужно всегда, но не относится
к текущему проекту:

1. Баланс с бонусом отдельной строкой мятного цвета.
2. Почта пользователя с меню.
3. Ряд иконочных кнопок `h3_ghost` размера `md`: профиль, ключи, переключение темы,
   поддержка.

## Хлебные крошки

| Свойство | Значение |
|---|---|
| Кегль | `h3_sm` 15px |
| Разделитель | `/`, отступ 8px по бокам |
| Максимальная ширина элемента | 200px, дальше многоточие |
| Цвет ссылки | `h3_text`, подчёркивание при наведении |
| Последний элемент | обычный текст, не ссылка |

Крошки живут в шапке слева и показывают путь целиком: «Мои проекты / Проект /
Виртуальные машины / Создание ВМ». Последний элемент — текущая страница, ссылкой
он не является.

## Сегментированный контрол

Переключение периода в калькуляторе: Месяц, День, Час. Активный сегмент подсвечен
подвижным индикатором, который переезжает между позициями. Реализован радиогруппой
(`role="radiogroup"`), поэтому работает стрелками с клавиатуры.

Годится для 2–4 взаимоисключающих режимов просмотра. Для выбора значения в форме
используем радио или список.

## Область прокрутки

Длинные списки завёрнуты в `ScrollArea`: полоса 4px, появляется при прокрутке,
у краёв градиентные тени. Тени включаются атрибутами `data-at-top` и `data-at-bottom`
и показывают, что список продолжается.

## Правила

**Возврат назад предсказуем.** Кнопка браузера возвращает туда, откуда пришли.
Модальные окна и выдвижные панели не должны ломать историю.

**Текущее положение видно.** Активный раздел в навигации выделен, и крошки
подтверждают путь. Пользователь в консоли часто приходит по прямой ссылке и должен
понять, где он оказался.

**Прямые ссылки работают.** Каждый экран консоли адресуем: проект, ресурс, вкладка
внутри ресурса. Состояние, которое нельзя вернуть по ссылке, теряется при
перезагрузке и не годится для инфраструктурной панели.

**Ссылка «пропустить навигацию».** В консоли до основного содержимого от начала
страницы лежит длинный список разделов. Клавиатурному пользователю нужна первая
по табуляции ссылка, ведущая сразу к содержимому.
